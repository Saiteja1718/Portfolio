# Sai Teja Dusari - Portfolio

React + Vite single-page portfolio.

## Run locally
    npm install
    npm run dev        # opens http://localhost:5173

## Production build
    npm run build      # output in dist/
    npm run preview

## Where to edit
- src/App.jsx: all content (EXP, RES, PRJ, SKILLS, LINKS, EMAIL at the top)
- src/styles.css: theme colors are the CSS variables in :root
- public/SaiTeja_Dusari_Resume.pdf: replace to update the resume download
- src/assets/photo.jpg: replace to change the photo

## Add project links
In src/App.jsx, add a `url` to each item in PRJ, for example `url:"https://github.com/..."`.
